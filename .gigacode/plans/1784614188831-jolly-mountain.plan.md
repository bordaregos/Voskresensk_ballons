# Plan: Project Refactoring and File Organization

## Overview
Refactor the balloon documentation generator project by organizing `.ui` files into a dedicated module and removing unnecessary files.

## Current State Analysis

### Project Structure
```
Voskresensk_ballons_pr/
├── src/                          # New layered architecture
│   ├── models/                   # Data models
│   ├── services/                 # Business logic
│   ├── ui/                       # UI layer (file_handler.py only)
│   └── utils/                    # Utilities
├── tests/                        # Empty - unused
├── backup/                       # Empty - unused
├── output/                       # Generated documents
├── main.py                       # Entry point (uses ui_logic.py)
├── ui_logic.py                   # Main UI logic (large file ~900 lines)
├── zakl_interface_v5-1_final.ui  # Old UI version
├── zakl_interface_v5-2_final.ui  # Current UI (v5-2)
├── zakl_interface_v5-3_test.ui   # Test UI version
├── test_integration.py           # Integration tests
├── test_ui_functionality.py      # UI tests
└── requirements.txt
```

### Findings
1. **3 `.ui` files in root directory** - should be organized
2. **Current UI**: `zakl_interface_v5-2_final.ui` is actively used
3. **Old UI versions**: `v5-1` and `v5-3_test` are unused
4. **Empty directories**: `tests/` and `backup/` serve no purpose
5. **Test files**: `test_integration.py` and `test_ui_functionality.py` are large but tests are outdated

## Implementation Plan

### Phase 1: Organize UI Files
1. Create `src/ui/designer/` directory
2. Move current UI file: `zakl_interface_v5-2_final.ui` → `src/ui/designer/`
3. Rename to standard name: `main_window.ui`
4. Update `ui_logic.py` to load from new path

### Phase 2: Remove Unnecessary Files
1. Delete old UI versions:
   - `zakl_interface_v5-1_final.ui`
   - `zakl_interface_v5-3_test.ui`
2. Remove test files:
   - `test_integration.py`
   - `test_ui_functionality.py`
3. Remove empty directories:
   - `tests/`
   - `backup/`

### Phase 3: Update Documentation
1. Update `README.md` to reflect new structure
2. Update migration summary if needed
3. Ensure `main.py` still works

## Detailed Steps

### Step 1: Organize UI Files
```bash
mkdir -p src/ui/designer
mv zakl_interface_v5-2_final.ui src/ui/designer/main_window.ui
```

### Step 2: Update ui_logic.py
- Change line: `loadUi("zakl_interface_v5-2_final.ui", self)`
- To: `loadUi("src/ui/designer/main_window.ui", self)`

### Step 3: Clean Up
```bash
rm zakl_interface_v5-1_final.ui
rm zakl_interface_v5-3_test.ui
rm test_integration.py
rm test_ui_functionality.py
rmdir tests/
rmdir backup/
```

### Step 4: Update main.py (if needed)
- Verify it loads UI correctly from new path
- Update path handling if necessary
